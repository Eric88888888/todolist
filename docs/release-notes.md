## 待办清单 v1.0.0

纯本地的 Windows 待办清单。数据只存在你自己的电脑上——不联网、不上传、不需要账号。

![界面](https://github.com/Eric88888888/todolist/raw/main/docs/usage-colors.png)

### 这次有什么

- **任务**：子任务（`2/3` 进度）、备注（失焦自动保存）、循环任务（每天 / 每周 / 每月，勾完自动顺延）
- **整理**：六种底色 + 置顶 + 拖拽手动排序（置顶区与非置顶区互不穿越）
- **查找**：搜索标题、备注、子任务标题
- **桌面**：关窗口收进托盘、单实例、到期弹 Windows 通知、`Ctrl+Shift+Space` 随手记一笔
- **安全**：数据存在本机 SQLite，每天自动备份，保留最近 7 份

### 下载哪个

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `Todolist_1.0.0_x64-setup.exe` | 2.3 MB | **推荐**。安装版；系统通知只有这个版本能弹 |
| `todolist.exe` | 8.1 MB | 绿色单文件，免安装；没有系统通知 |

### 安装

1. 双击 `setup.exe`，装到当前用户目录（**不需要管理员权限**）
2. 首次启动自动建库并做一次备份
3. 关闭窗口是收到托盘，右键托盘图标可以退出

### 运行环境

- **系统**：Windows 10 1809 及以上 / Windows 11（x64）
- **WebView2 运行时**：Win11 自带；Win10 上若缺失，安装包会自动下载一次（需要联网）
- 装好之后 **完全离线可用**，不需要 .NET / Java / Node 等任何运行时
- **磁盘**：安装约 10 MB；数据在 `%APPDATA%`，卸载不删数据

### 已知限制

- 绿色版不弹系统通知（Windows 的 AUMID 机制要求安装形态提供开始菜单快捷方式）
- 系统「勿扰 / 专注助手」开启时会吞掉横幅，通知仍在操作中心里
- 拖拽排序只在「全部」视图下可用

### 反馈

有问题欢迎开 issue，附上 `%APPDATA%\com.dsh.todolist\app.log` 会更好定位。
